Documentação do sistema de layout

Estruturas que respiram.

Layout é a forma como o conteúdo encontra espaço, ordem e prioridade. No Fokus Styles, a composição começa pela estrutura do documento e evolui com classes previsíveis para containers, linhas, colunas, pilhas e espaçamentos.

Este guia parte dos fundamentos e chega ao laboratório. Em cada etapa, você verá o que o padrão resolve, uma demonstração visual, o HTML correspondente e uma comparação entre uma aplicação recomendada e uma aplicação que deve ser evitada.

01 · Fundamentos

Antes da classe, vem a intenção.

Um bom layout não começa escolhendo uma classe ao acaso. Começa entendendo a relação entre o conteúdo, a largura disponível, a ordem de leitura e as ações que a pessoa precisa realizar.

Fluxo natural

Deixe o conteúdo seguir o fluxo do documento sempre que possível. Isso melhora zoom, leitura assistiva e adaptação para diferentes telas.

Relações explícitas

Use containers para limitar leitura, linhas para agrupar colunas e stacks para declarar uma sequência vertical.

Adaptação progressiva

Comece com uma composição funcional em uma coluna e adicione variações apenas quando o espaço justificar.

Use assim

Escolha a estrutura pelo papel que ela desempenha no conteúdo. Um container organiza a largura; uma linha organiza colunas; uma pilha organiza a sequência vertical.

Evite assim

Use dezenas de margens arbitrárias para compensar uma estrutura que não foi definida. O resultado fica frágil quando o texto muda ou a tela diminui.

02 · Container

Uma largura que respeita a leitura.

O `.fs-container` centraliza o conteúdo e limita sua largura máxima nos breakpoints do sistema. Ele evita linhas excessivamente longas sem exigir que cada página invente seus próprios limites.

Conteúdo dentro de `.fs-container`Largura fluida no início; largura máxima conforme o viewport.
HTML · Container
<main class="fs-container">
    <h1>Título da página</h1>
    <p>Conteúdo com largura confortável para leitura.</p>
</main>

Use assim

Aplique o container como uma moldura semântica para o conteúdo principal, seções de documentação e áreas que precisam manter uma largura confortável.

Evite assim

Fixe uma largura em pixels no conteúdo inteiro ou crie um container diferente para cada tela. A largura máxima oficial já responde aos breakpoints do sistema.

03 · Grid

Colunas que se reorganizam.

As classes de grid do Fokus Styles usam `.fs-row` e classes de coluna responsivas. O padrão permite começar com uma coluna e distribuir o conteúdo em telas maiores, sem duplicar markup.

01
02
03
HTML · Grid responsivo
<div class="fs-container">
    <div class="fs-row fs-row-cols-1 fs-row-cols-md-3">
        <article>Primeiro bloco</article>
        <article>Segundo bloco</article>
        <article>Terceiro bloco</article>
    </div>
</div>

Use assim

Defina a quantidade de colunas pelo conteúdo e declare a variação responsiva com as classes oficiais. Mantenha cada item independente e compreensível fora da grade.

Evite assim

Use posições absolutas para simular colunas ou dependa de quebras manuais de linha. O grid deve responder ao espaço disponível.

04 · Flex

Linhas para relações simples.

O `.fs-row` é baseado em Flexbox e pode organizar grupos horizontais que precisam compartilhar espaço. Use-o para relações diretas, como ações, métricas ou itens de uma mesma linha.

MarcaConteúdo principalAção
HTML · Linha flexível
<div class="fs-row">
    <div class="fs-col">Conteúdo principal</div>
    <div class="fs-col-auto">Ação</div>
</div>

Use assim

Use a linha quando os elementos têm uma relação horizontal clara e podem compartilhar o mesmo contexto de leitura.

Evite assim

Force toda a página a ser uma única linha flexível. Isso dificulta a leitura, cria dependências entre áreas e pode gerar overflow.

05 · Espaçamento

Ritmo antes de distância.

Espaçamento não é um conjunto de empurrões visuais. Ele comunica agrupamento, separação e prioridade. Para sequências verticais, o `.fs-stack` torna explícita a relação entre os elementos e evita margens especiais no último filho.

Contexto
Conteúdo relacionado
Ação seguinte
HTML · Stack
<section class="fs-stack fs-stack-gap-3">
    <p>Contexto da tarefa</p>
    <div>Conteúdo relacionado</div>
    <a href="/proximo-passo">Continuar</a>
</section>

Use assim

Use uma escala de espaçamento consistente e aplique o gap pelo relacionamento entre os filhos, não por exceções isoladas.

Evite assim

Empilhe margens diferentes sem uma regra clara. Isso gera colapsos, ritmos imprevisíveis e correções difíceis de manter.

06 · Responsividade

O mesmo conteúdo, três leituras.

Responsividade não é esconder conteúdo para caber. É permitir que a estrutura se reorganize sem perder significado. O exemplo abaixo começa empilhado e passa a usar três colunas a partir do breakpoint `md`.

Use assim

Comece pela menor largura, preserve a ordem semântica e amplie a composição apenas quando os elementos tiverem espaço real para respirar.

Evite assim

Projete primeiro para desktop e tente consertar o mobile escondendo conteúdo ou reduzindo o texto até ele perder sentido.
