Helpers que organizam.

Helpers resolvem necessidades recorrentes de composição sem transformar cada tela em uma folha de estilos particular. Eles aproximam o HTML da intenção: empilhar, agrupar, limitar largura, esconder visualmente ou ajustar ritmo.

01 · Composição

Descreva relações, não coordenadas.

Use `fs-container`, `fs-stack`, `fs-cluster` e `fs-grid` para declarar como os elementos se relacionam. A composição se adapta ao espaço disponível.

02 · Ritmo

Espaço é parte da hierarquia.

Os helpers de espaçamento permitem comunicar proximidade e separação usando a escala do sistema, sem valores arbitrários espalhados pela aplicação.

03 · Visibilidade

Esconder visualmente não é apagar.

Helpers de visibilidade devem preservar a informação quando ela é necessária para tecnologias assistivas, ou refletir uma decisão real de responsividade quando o conteúdo não cabe.

Esta orientação é lida por tecnologia assistiva, mas não ocupa espaço visual.

04 · Acessibilidade

Um helper bom não cria dívida.

Priorize HTML semântico, ordem de foco e leitura natural. Use utilitários de visibilidade com intenção documentada e confirme o resultado em zoom, teclado e leitor de tela.

Composição
Use a classe para expressar relação entre elementos, não para substituir estrutura semântica.
Responsividade
Teste o ponto de quebra com conteúdo real; não esconda ações essenciais apenas para economizar espaço.
Manutenção
Prefira a escala e as classes existentes antes de adicionar um helper local com o mesmo propósito.
