Interface que fala a mesma língua.

Fokus Styles é um framework CSS de código livre para construir experiências consistentes, acessíveis e responsivas em todos os subsistemas Fokus.

O que é o Fokus Styles?

Uma base visual e técnica compartilhada para produtos digitais que precisam evoluir juntos.

01

Design system

Tokens semânticos, temas claro e escuro, tipografia, cores, espaçamento e padrões de interface.

02

Feito para a web

HTML semântico, CSS moderno e JavaScript vanilla, sem exigir um framework de aplicação.

03

Open source

Disponível no GitHub e distribuído pelo NPM para uso, estudo, colaboração e evolução contínua.

Tecnologias e definições

As escolhas que orientam a construção e o uso do sistema.

HTML semântico

Elementos nativos e relações corretas entre títulos, navegação, conteúdo, formulários e ações.

CSS moderno

Custom properties, Grid, Flexbox, media queries e camadas de composição com nomes previsíveis.

JavaScript vanilla

Interações progressivas, eventos acessíveis e APIs nativas sem dependência obrigatória de biblioteca.

Acessibilidade e responsividade

Os padrões devem funcionar para mais pessoas, dispositivos e formas de interação.

Acessibilidade

Contraste, foco visível, navegação por teclado, textos compreensíveis, rótulos e estados anunciáveis.

Responsividade

Conteúdo adaptável do celular ao desktop, sem depender de uma largura ou dispositivo específico.

Tags e atributos

Use a tag adequada para cada finalidade, com atributos ARIA apenas quando o HTML nativo não for suficiente.
