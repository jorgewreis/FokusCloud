A fundação do ecossistema Fokus

Interface que fala a mesma língua.

Toda experiência digital começa antes do primeiro botão: começa na escolha de uma linguagem, na forma como o conteúdo se organiza e na confiança que a interface transmite. O Fokus Styles nasceu para transformar essas decisões em uma base compartilhada, clara e viva.

Ele é um framework CSS de código livre, acompanhado de padrões de interface e interações em JavaScript vanilla, criado para que equipes possam construir produtos distintos sem perder coerência, acessibilidade ou personalidade.

De onde viemos

Uma história sobre consistência.

O framework não começou como um catálogo de componentes. Começou como uma pergunta simples: por que cada produto precisa reaprender a mesma lição visual?

Ao criar o ecossistema Fokus, percebemos que diferentes domínios — jurídico, imobiliário, administrativo e educacional — exigem vocabulários próprios. Ainda assim, todos compartilham necessidades fundamentais: uma navegação que faça sentido, formulários que não criem insegurança, mensagens que orientem e uma hierarquia visual que respeite o tempo de quem usa.

Sem uma base comum, pequenas decisões se multiplicam. Um espaçamento muda de tela para tela, uma cor perde significado, um estado de erro é apresentado de maneira diferente e a acessibilidade fica dependente da memória individual de cada pessoa desenvolvedora. O trabalho deixa de ser resolver o problema do público e passa a ser reconstruir infraestrutura.

O Fokus Styles foi criado para interromper esse ciclo. Ele reúne decisões que podem ser compartilhadas, documentadas e melhoradas. Assim, cada produto pode concentrar sua energia no contexto que o torna especial, enquanto a fundação cuida da previsibilidade que torna a experiência confortável.

O objetivo não é uniformizar produtos.É dar a eles uma gramática comum para que cada um possa contar sua própria história.
Por que ele existe

Princípios que guiam o sistema.

Um sistema visual só é realmente útil quando ajuda pessoas diferentes a tomar decisões coerentes, mesmo em momentos e produtos diferentes. Estes princípios orientam o desenho, a implementação, a revisão e a evolução de cada padrão do Fokus Styles.

01

Clareza antes da decoração

Uma interface pode ter personalidade sem transformar cada tela em um enigma. Cores, tamanhos, contrastes e espaços devem explicar a hierarquia do conteúdo, revelar relações e conduzir a pessoa até a próxima decisão com o mínimo de esforço. Antes de perguntar se um elemento é chamativo, perguntamos se ele é compreensível.

02

Reutilizar é cuidar

Reutilizar não é repetir mecanicamente: é preservar uma decisão que já foi pensada, testada e documentada. Um padrão compartilhado reduz divergências, acelera a manutenção e permite que uma melhoria de acessibilidade, segurança ou usabilidade alcance muitos lugares ao mesmo tempo. Cada componente consistente devolve tempo para a equipe cuidar do problema real do produto.

03

Contexto sem dependência

O Styles deve apoiar o produto sem aprisioná-lo a uma ferramenta específica. Por isso, seu núcleo se aproxima das tecnologias fundamentais da web e pode ser usado progressivamente, com ou sem um framework de aplicação. A base permanece leve, portátil e compreensível, enquanto cada produto conserva liberdade para expressar seu domínio e suas necessidades.

A caixa de ferramentas

Construído com a web que você já conhece.

Escolhemos tecnologias abertas e amplamente compreendidas porque um sistema visual deve aproximar a equipe do produto, e não criar uma nova camada de tradução. A familiaridade reduz o tempo de entrada, facilita a colaboração e torna as decisões mais fáceis de inspecionar, ensinar e manter.

HTML semântico

Tags corretas comunicam estrutura para pessoas, navegadores, mecanismos de busca e tecnologias assistivas. Um link navega; um botão executa uma ação; um título anuncia uma seção. Essa distinção aparentemente simples melhora teclado, leitura por tecnologias assistivas, manutenção e entendimento do código por toda a equipe.

CSS moderno

Custom properties, Grid, Flexbox, media queries e camadas de composição formam uma base expressiva para criar interfaces fluidas. Em vez de desenhar uma versão isolada para cada tela, descrevemos relações que se reorganizam conforme o espaço disponível, preservando ritmo, contraste e legibilidade.

JavaScript vanilla

Interações progressivas usam APIs nativas e respeitam o HTML antes de adicionar comportamento. Isso mantém o código transparente, reduz dependências e permite que a experiência continue útil quando uma camada opcional de JavaScript falhar, carregar depois ou for substituída no futuro.

A11Y
Um compromisso, não um recurso extra

Acessibilidade faz parte da definição de pronto.

O Fokus Styles trata acessibilidade como critério de qualidade desde a primeira decisão. Contraste suficiente, foco visível, navegação por teclado, rótulos associados, mensagens compreensíveis e estados anunciáveis são partes do comportamento esperado, não uma etapa para depois.

Responsividade segue a mesma lógica. O conteúdo deve se reorganizar para telas pequenas, grandes, touch, teclado e diferentes níveis de zoom. Em vez de desenhar para um dispositivo específico, construímos relações flexíveis que acompanham a pessoa onde ela estiver.

  • Use HTML nativo antes de recorrer a ARIA.
  • Não esconda informação essencial apenas por causa do tamanho da tela.
  • Teste foco, contraste, zoom e navegação sem mouse.
Comece em poucos minutos

Aberto para usar, estudar e melhorar.

O framework é gratuito porque uma boa fundação se torna mais forte quando pode ser examinada, adaptada e compartilhada. O acesso livre permite que estudantes aprendam com um sistema real, que equipes evitem dependências desnecessárias e que a comunidade aponte melhorias que talvez não víssemos sozinhos.

Gratuito não significa sem direção. O projeto tem convenções, documentação, versionamento e um compromisso explícito com qualidade. Você pode começar pequeno, usar apenas os tokens ou adotar gradualmente os padrões que fizerem sentido para seu produto.
