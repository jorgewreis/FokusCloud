O que é o Fokus Cloud?

Fokus Cloud é a plataforma que reúne o ecossistema Fokus. A proposta é compartilhar uma base de tecnologia e identidade entre produtos especializados, mantendo cada produto com seu próprio foco. Conheça o portfólio de produtos Fokus Cloud.

Qual é a diferença entre Fokus Cloud e Fokus Styles?

Fokus Cloud é a plataforma do ecossistema. Fokus Styles é o framework CSS de código aberto usado para construir interfaces: oferece tokens, temas, componentes e interações em JavaScript. Pode ser instalado e usado em projetos independentes do Fokus Cloud.

O que já está disponível?

O Fokus Styles está disponível gratuitamente no npm, com código no GitHub e documentação em português. Fokus Law, voltado à gestão de processos e rotinas judiciais, e Fokus Lead, voltado a relacionamentos e operações imobiliárias, estão em desenvolvimento.

Como começar com o Fokus Styles?

Acesse a instalação do framework e os guias de layout CSS responsivo, formulários e validação, components, helpers e utilities, com exemplos de HTML e orientações de uso.
