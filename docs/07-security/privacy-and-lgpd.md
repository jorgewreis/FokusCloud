# Privacidade e LGPD

Este arquivo deve registrar dados pessoais tratados pelo Fokus Cloud e seus produtos derivados.

## Dados pessoais iniciais

- Nome.
- E-mail.
- Empresa.
- Perfil de acesso.
- Historico de assinatura e eventos administrativos.

## Pontos a definir

- Bases legais.
- Politica de retencao.
- Exclusao ou anonimizacao.
- Direitos do titular.
- Encarregado e canal de contato.
- Dados especificos do Fokus Law.
- Dados especificos do Fokus Lead.
