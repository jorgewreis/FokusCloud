# Testes e qualidade

## Validacoes minimas

- Testes automatizados Laravel quando houver alteracao de backend.
- Validacao de sintaxe JavaScript quando houver alteracao de JS.
- Verificacao de links e assets quando houver reorganizacao de HTML, CSS ou arquivos publicos.
- Laravel Pint antes de considerar codigo PHP pronto.

## A complementar

- Matriz de testes por modulo.
- Testes de permissao.
- Testes de isolamento multiempresa.
- Testes de catalogo comercial e assinatura.
