# Glossario

| Termo | Definicao inicial |
| --- | --- |
| Fokus Cloud | Plataforma base do ecossistema. |
| Fokus Law | Produto derivado voltado ao dominio juridico. |
| Fokus Lead | Produto derivado voltado ao dominio imobiliario e comercial. |
| Empresa | Organizacao cliente que possui usuarios, assinaturas e dados isolados. |
| Modulo | Conjunto funcional pertencente a plataforma base ou a um produto derivado. |
| Plano | Oferta comercial com preco, limites e funcionalidades. |
| Voucher | Beneficio comercial aplicado sob regras especificas. |

## A complementar

Novos termos devem ser adicionados quando aparecerem em regras de negocio, telas, banco de dados ou contratos comerciais.
