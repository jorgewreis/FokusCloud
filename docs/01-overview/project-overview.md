# Visao do projeto

## Proposito

O Fokus Cloud e uma plataforma SaaS multiempresa criada para sustentar produtos digitais especializados a partir de uma base comum de conta, empresa, assinatura, catalogo, permissoes e governanca.

## Produtos derivados

| Produto | Papel |
| --- | --- |
| Fokus Cloud | Base comum da plataforma. |
| Fokus Law | Produto juridico derivado. |
| Fokus Lead | Produto imobiliario e comercial derivado. |

## Modelo alvo

O projeto deve crescer por modulos independentes, sempre preservando a separacao entre plataforma base e dominios especificos.

## A complementar

- Publico-alvo prioritario de cada produto.
- Principais fluxos de uso.
- Roadmap macro.
- Criterios de sucesso do projeto.
