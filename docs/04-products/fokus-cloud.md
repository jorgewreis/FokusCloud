# Fokus Cloud

## Papel

Fokus Cloud e a plataforma base. Ele concentra recursos comuns que sustentam todos os produtos derivados.

## Escopo inicial

- Autenticacao.
- Empresas.
- Usuarios.
- Permissoes.
- Assinaturas.
- Catalogo comercial.
- Vouchers.
- Auditoria.
- Backoffice.

## Fora do escopo

Regras especificas juridicas ou imobiliarias nao devem ser implementadas diretamente na plataforma base.
